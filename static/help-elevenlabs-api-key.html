How to get an ElevenLabs API key

ElevenLabs Scribe is the only backend this project supports that returns a per-word confidence score, which is what lets a document highlight the words the model was unsure of instead of asking you to re-read the whole hour. Getting a key takes a few minutes, and there is exactly one step people miss.

Six steps, one of which bites

  1. Sign in to ElevenLabs

    Sign in or register at elevenlabs.io. There is a free tier. Speech-to-text is billed against your plan’s credit quota rather than a per-hour rupee rate, which is why this app’s spend meter counts jobs for ElevenLabs instead of inventing a currency figure.

  2. Open Developers, then API Keys

    Click Developers in the left sidebar, then the API Keys tab. The same page is reachable from My Workspace in the lower left corner, and directly at elevenlabs.io/app/settings/api-keys.

  3. Create a key and give it a name that means something

    Press + Create Key. Name it for where it is going to live: marathi-transcriber-laptop beats key 3 on the day you need to revoke exactly one of them.

  4. Enable Speech to Text on the key

    This is the step people miss. An ElevenLabs key is restricted by default: it grants access to nothing until you tick the products it may use. Find Speech to Text in the permission list and enable it.

    Skip this and the key is real, valid, and completely useless for transcription. Every request comes back 401, which reads exactly like a typo in the key, and you will spend twenty minutes re-copying a key that was never the problem.

  5. Set a credit limit while you are there

    Optional, and worth the ten seconds: each key can carry its own credit cap. A capped key turns a runaway loop into a failed request rather than an invoice. If the key is going anywhere near a script you are still writing, cap it.

  6. Copy the key, then paste it into the app

    The full value is shown only at creation. Afterwards the list shows the name and the last four characters and nothing else.

    Open the transcriber, pick ElevenLabs Scribe under Transcribed by, paste, and press Start session. The key is verified against your account before any audio moves, then held in the server’s memory for the session only. One session is one provider, so an ElevenLabs key can never be sent to Sarvam.

Use the key

The header name is xi-api-key. Like Sarvam’s, it is not an Authorization header and takes no Bearer prefix.

From the command line

export ELEVENLABS_API_KEY=your_key_here
export SCRIBE_LANG=mar           # say Marathi; auto-detect can pick English
ASR=elevenlabs .venv/bin/python transcribe.py meeting.m4a

Straight against the API

curl -X POST https://api.elevenlabs.io/v1/speech-to-text \
  -H "xi-api-key: $ELEVENLABS_API_KEY" \
  -F model_id=scribe_v2 \
  -F language_code=mar \
  -F diarize=true \
  -F timestamps_granularity=word \
  -F file=@meeting.m4a

# 401 here with a key you just copied? The key is probably
# missing the Speech to Text permission. See step 4.

Before you upload

  • A restricted key looks exactly like a wrong key. If a freshly created key returns 401 on a transcription request, it is almost certainly missing the Speech to Text permission rather than mistyped.
  • Set the language explicitly. On code-switched Marathi and English audio, auto-detect can settle on English and hand back a translated transcript instead of a Marathi one. language_code=mar costs nothing and removes the coin flip.
  • Keyword biasing bills 20% extra. Scribe’s keyterms field is genuinely useful for village names and scheme acronyms, but the surcharge applies whenever the field is present, whether or not any term is ever matched.
  • Re-tune your confidence threshold. Scribe returns a logprob, and exp(logprob) is a different distribution from Whisper’s probabilities. Carry a threshold over unchanged and you get either every word flagged or none of them. Measure it on one real meeting.
  • One request covers upload and transcription. There is no progress to poll for, so a long file simply takes as long as it takes. This app draws an estimated bar from elapsed time rather than pretending to know.

Questions people actually ask

Why does my new ElevenLabs API key return 401?

Because new keys are restricted by default and grant no product access until you enable it. Open the key in Developers > API Keys and tick Speech to Text. A key without that permission is valid but rejects every transcription request, which is indistinguishable from a wrong key.

What is the header name for ElevenLabs authentication?

xi-api-key. It is not an Authorization header and there is no Bearer prefix.

Can I see an ElevenLabs API key again after creating it?

No. The full value appears only at creation. Afterwards the dashboard shows the key's name and its last four characters. If you lose it, create a new key and delete the old one.

How long a recording can Scribe take?

Up to 3 GB and up to 10 hours per request in standard mode, which is far beyond any normal meeting. Sarvam, by contrast, caps a single file at 2 hours.

How good is Scribe at Marathi?

ElevenLabs rates Marathi in its high-accuracy band, between 5% and 10% word error rate. For code-switched meeting audio it is a reasonable choice, and it is the only option here that reports per-word confidence, so uncertain words can be highlighted for review.

Does Scribe label speakers?

Yes, up to 32 speakers with diarization enabled, and unlike Sarvam it does not charge a different rate for it.

Can I limit what a key is allowed to spend?

Yes. Each key can carry its own credit cap, set when you create it or later by editing it. It is the cheapest insurance there is against a loop you did not mean to write.
