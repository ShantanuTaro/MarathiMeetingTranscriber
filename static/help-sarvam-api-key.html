How to get a Sarvam AI API key

Sarvam is an India-first model provider, and saaras:v4 is the best Marathi transcription this project has measured. Getting a key takes about five minutes and costs nothing: a new account comes with free credit and no card is asked for. Here is the whole path, plus the three things that quietly spend that credit with nothing to show for it.

Five steps to a working key

  1. Create a Sarvam account

    Go to dashboard.sarvam.ai and sign up with an email address or a Google account. Verification is normally instant. No payment card is asked for, which is the point of starting here rather than on a plan.

  2. Open the API Keys section

    In the dashboard, find API Keys in the sidebar. Sarvam moves its dashboard around occasionally, so if the sidebar looks different, look for the words rather than the position.

    Worth knowing before you make several: rate limits are counted per account, not per key. Extra keys separate projects and let you revoke one without killing the others. They do not buy you more throughput.

  3. Create the key and copy it immediately

    Create a new key. Copy it before you navigate away. The dashboard shows the full value exactly once, at creation. There is no “show again”: if you lose it, the only route is to delete that key and generate another.

    Paste it somewhere safe for a moment. Not into a git repository, not into a chat window, and not into a file you are about to commit.

  4. Check what you have to spend

    A new account carries ₹100 of credit, universal across Sarvam’s APIs, with no expiry. Speech-to-text is ₹30 per hour of audio, or ₹45 per hour with speaker labels on, billed per second.

    So the free grant is roughly 2h13m of diarized audio: two hour-long meetings, and not a minute more. That number is worth holding in your head before you upload anything, because it goes faster than it sounds.

  5. Paste it into the app

    Open the transcriber, pick Sarvam under Transcribed by, and the key form opens by itself. Paste the key and press Start session.

    The key is checked against Sarvam before any audio moves, by creating a job and never starting it. Sarvam bills nothing until a job starts, so verifying costs zero and a bad key fails immediately rather than after an hour-long upload. It then lives in the server’s memory for the session only: never written to disk, never sent back to the page, never included in any status response. End session erases it, and so does restarting the server.

    Optionally type what your dashboard says your credit balance is. There is no API to read it, so the meter can only subtract from a number you supply.

Use the key

The header name is api-subscription-key. Not Authorization, not Bearer: a wrong header name returns 401 and reads exactly like a wrong key.

From the command line

export SARVAM_API_KEY=your_key_here
export SARVAM_DIARIZE=0          # single voice? Rs30/hr instead of Rs45
.venv/bin/python transcribe.py meeting.m4a

Straight against the API

curl -X POST https://api.sarvam.ai/speech-to-text/job/v1 \
  -H "api-subscription-key: $SARVAM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"job_parameters": {"model": "saaras:v4",
                          "with_diarization": true,
                          "with_timestamps": true}}'

# Creating a job is free. Billing starts at /start, not here.

What quietly spends the credit

  • Billing starts when the job starts, not when it succeeds. A run that comes back empty, errors, or gets stopped is billed in full for the whole duration of the audio. There is no partial charge and no refund.
  • There is no cancel endpoint. Once a job has started, it runs to completion on Sarvam’s side and bills, whatever your end does. Pressing Stop only stops the polling.
  • A wrong Content-Type returns an empty transcript, billed in full. Sarvam decodes the uploaded blob by its declared mime type. Declare the wrong one and you get a blank transcript with the job marked Success. This app reads the real container with ffprobe rather than trusting the file extension, because the first real recording it ever handled was raw AAC named .mp3.
  • Speaker labels are a price tier, not a switch. Diarization takes the rate from ₹30 to ₹45 an hour, a 50% premium. On a single-voice recording it buys nothing. SARVAM_DIARIZE=0, or the equivalent in your own code, is a third off the bill.

Questions people actually ask

Do I need a credit card to get a Sarvam API key?

No. Signing up at dashboard.sarvam.ai takes an email address or a Google account, and a new account is credited with Rs100 automatically. A card is only needed when you want to add credit beyond that.

How much Marathi audio does the free credit cover?

About 2 hours 13 minutes with speaker labels on, at Rs45 per hour of audio. With diarization off it is Rs30 per hour, so roughly 3 hours 20 minutes. Billing is per second of audio, not per request.

I lost my API key. Can I see it again?

No. The dashboard shows the full key only at the moment of creation. Delete that key and create a new one; anything using the old key will stop working, which is exactly what you want if you lost it because it leaked.

What is the header name for Sarvam authentication?

api-subscription-key. It is not an Authorization header and there is no Bearer prefix. Sending the right key under the wrong header name returns 401 and looks identical to sending a bad key.

Is my key safe in this app?

It is held in the server's memory for the length of the session and nowhere else: never written to disk, never sent back to the browser, never included in any job or status response, and never handed to a different provider. Ending the session or restarting the server erases it. Closing the tab does not, so use the End session button.

Why is my transcript empty even though the job succeeded?

Almost always a Content-Type that does not match the actual audio container. Sarvam decodes by the declared type, produces nothing usable, and still marks the job successful and bills it. Check the real format with ffprobe rather than trusting the file extension.

Can I send a recording longer than two hours?

Not in one job: Sarvam caps a single file at 2 hours. Split it into parts and stitch the timestamps back together. This app does that automatically, cutting into equal parts and re-encoding them so a 269 MB source uploads as two 34 MB parts.
